# Dexy Investor Deck Narrative Plan

## Audience
- Silicon Valley style pre-seed / seed crypto investors
- strategic operators or advisors
- early design partners

## Objective
Convince the audience that Dexy is not another dashboard, but a Hyperliquid-native operator control layer with a credible wedge: wallet-level risk attribution and event alerts for human operators first.

## Narrative Arc
1. Hyperliquid users do not primarily need more signal.
2. They need visibility into risk, leakage, and explanation.
3. Existing tools are fragmented.
4. Dexy is the wallet-aware control layer.
5. Start with subscription and workflow.
6. Expand to API / MCP / x402 later.
