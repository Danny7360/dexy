# Dexy Business Plan

## 1. Company Snapshot

### Working name

Dexy

### Category

Hyperliquid-native operator tooling

### One-line pitch

Dexy helps Hyperliquid operators understand where risk is building, where profit is leaking, and why realized PnL diverges from intuition.

### Stage

Pre-product / thesis validation

### Starting mode

Founder-led, OPC-friendly, human-first workflow product

## 2. Market Opportunity

Dexy sits at the intersection of:

- onchain trading analytics
- wallet-level risk monitoring
- post-trade attribution
- event-aware execution context

This is best understood as a crypto-native version of a lightweight:

- risk console
- TCA / execution analytics layer
- attribution dashboard
- operator workstation

### Why this exists now

- Hyperliquid concentrates active perp users
- public observability lowers build cost
- third-party tooling proves need but remains fragmented
- AI lowers explanation cost, but not workflow design cost

## 3. Customer

### Primary ICP

Hyperliquid middle-tier operators:

- active traders with non-trivial notional exposure
- strategy operators
- systematic bot runners
- builder-adjacent users who need persistent visibility

### Anti-ICP

- retail “what should I buy” users
- alpha group customers
- fully autonomous agents as first buyers
- top proprietary desks with strong in-house tooling

## 4. Product

### Core promise

Dexy is not a research terminal. It is an action-priority layer.

### V1 feature set

- wallet input
- current risk snapshot
- liquidation distance view
- funding and fee drag
- simple attribution summary
- Telegram alerts
- minimal web dashboard

### What is intentionally excluded

- copy trading
- autonomous execution
- strategy recommendations
- custody
- full multi-venue portfolio support
- x402-first payments

## 5. GTM

### Phase 1: narrow and dense

Go where operator pain is concentrated:

- X
- Telegram groups
- Hyperliquid-native communities
- builder/operator circles

### Messaging

Do not market Dexy as:

- AI copilot
- signal engine
- alpha feed

Do market Dexy as:

- “see your riskiest position before it becomes a problem”
- “know where your profit is leaking”
- “understand why your realized PnL looks wrong”

### Distribution

1. wallet review demos
2. Telegram-native alerts
3. weekly case-study content
4. lightweight operator-facing API later

## 6. Revenue Model

### Initial revenue model

Subscription:

- free
- pro
- operator / team

Likely pricing should sit in the same broad market reality as comparable analytics products:

- Nansen consumer/pro-style pricing
- CoinMarketMan trader tooling pricing
- HyperTracker-style premium data plans

### Later revenue layers

- API
- webhooks
- MCP
- x402 for machine usage

### Longest-term upside

If Dexy becomes part of execution or routing workflow, revenue can move from seat-based SaaS to flow-linked revenue.

That is where the ceiling materially expands.

## 7. Market Floor vs Ceiling

### Commercial floor

If Dexy works only as a niche professional workflow:

- dozens of paying users
- several hundred dollars per month blended ARPU across tiers and team usage
- a viable small-but-real operator SaaS

This can already support an OPC-style business.

### Commercial ceiling

The ceiling depends on whether Dexy remains:

- a dashboard product

or becomes:

- a workflow product
- an API / integration layer
- eventually a fee-on-flow or routing-adjacent product

Seat-based analytics products have decent floors and modest ceilings.
Workflow and flow-linked products have much higher ceilings.

## 8. Comparable Products and Lessons

### Nansen

Lesson:

- wallet analytics is monetizable
- “public data” does not kill SaaS if packaging, semantics, and workflow are strong

### CoinMarketMan / HyperTracker

Lesson:

- trader dashboards can be packaged, sold, and tiered
- Hyperliquid intelligence is already a paid category

### 3Commas

Lesson:

- simple tools can become meaningful businesses when they sit inside operator workflow
- workflow is more valuable than analytics alone

### Hyperdash

Lesson:

- once tooling touches execution and traffic, monetization can shift from subscription to fee share

### trade[XYZ]

Lesson:

- Hyperliquid ecosystem businesses can participate in fee economics when they become part of the trading surface

## 9. Why Dexy Might Win

Dexy does not need to beat everyone at data.

It needs to be better at:

1. compressing risk into priority
2. compressing cost into explanation
3. compressing complexity into workflow

### The strategic wedge

The real wedge is not “analysis.”

The wedge is:

- persistence
- personalization
- clarity
- action order

## 10. Why Dexy Might Fail

The thesis fails if any of these prove true:

1. users say existing tools are enough
2. users do not return repeatedly
3. users like the dashboard but do not change behavior
4. no one pays for attribution/risk, only for alpha

## 11. Product Development Plan

### 0-30 days

- founder learning and problem immersion
- wallet review exercises
- user interviews
- Figma / spec / no-code or lightweight mockups

### 30-60 days

- basic data ingestion
- Telegram alert logic
- single-wallet dashboard
- funding + fee + risk summaries

### 60-90 days

- user testing
- report / replay functionality
- pricing experiments
- decide whether to deepen attribution or alerting first

## 12. Financing View

This does not need venture financing to begin.

Best initial posture:

- founder-led
- validate with a narrow ICP
- reach first paid users
- decide later whether to remain a cash-flow software business or expand into a larger workflow/flow business

## 13. Strategic Recommendation

Dexy is worth pursuing if the founder wants:

- a real operator problem
- a narrow but credible wedge
- a human-first workflow product
- an OPC-friendly starting point

Dexy is not the right path if the founder wants:

- a pure alpha business
- a high-hype agent story from day one
- a giant TAM consumer trading platform immediately
